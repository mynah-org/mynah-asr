## Contracts that the evidence currently supports (for freezing; each line is a reading of the matrix, not a new result)

- **Data contract.** At least the 4 A2-type human sources (~120-130 h physical, many speakers; VP-type sources
  teacher-filtered at t50), plus a teacher-labelled web source when one exists. Its benefit was shown out of domain
  only (FR), and only once the horizon was long enough (FR-G1 HARM at 8k vs G1E NULL / OOD -4.55 at 11,881). Every
  bank (DEV, OOD, FINAL) is built and sealed before any score.
- **Exposure contract.** Keep the full WSD horizon. Shortening it to 0.6x costs +2.68 (ES S1); doubling it in FR
  gained -3.5 / -4.0. The ES value is 12,670 steps / 4.60 passes for 126 h. For a 216 h G1E-type pool the evidence
  favours >= 23,762 steps. The passes-vs-steps reading is unresolved.
- **Compute contract.** S5 on GB10: ~-33 % GPU at equal macro on ES (two seeds). Cross-language replication is
  pending (S5-FR).
- **EOU contract.** Stage 2 v4 unchanged, judged with the serving protocol (reset) on DEV + OOD, plus an
  internal-pause class bank. Validated on IT and FR only. The declared limitation is internal-pause false endpoints.
